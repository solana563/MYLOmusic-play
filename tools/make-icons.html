MYLO — icon generator

Renders the standalone logo to real PNG files for the PWA manifest and app icons. Canvas rasterising (not SVG) because Chrome's installability check rejects SVG manifest icons.

Serve this page over http(s) from the repository root so the logo can be safely rasterized, then use the download buttons. Commit the results into assets/icons/.

App icon files

  • assets/icons/icon-192.png — 192×192, purpose: any
  • assets/icons/icon-512.png — 512×512, purpose: any
  • assets/icons/icon-maskable-512.png — 512×512, purpose: maskable (60% inset so Android's circle crop is safe)
  • icon-1024.png — 1024×1024 high-resolution standalone mark
