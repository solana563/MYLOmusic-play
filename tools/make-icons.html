MYLO — icon generator

Renders the official wordmark to real PNG files for the PWA manifest and native shells. Canvas rasterising (not SVG) because Chrome's installability check rejects SVG manifest icons.

Run this page over http(s) (or open the file directly — no server needed) and use the download buttons. Commit the results into assets/icons/.

Required files

  • assets/icons/icon-192.png — 192×192, purpose: any
  • assets/icons/icon-512.png — 512×512, purpose: any
  • assets/icons/icon-maskable-512.png — 512×512, purpose: maskable (60% inset so Android's circle crop is safe)
  • resources/icon.png — 1024×1024 source for @capacitor/assets (adaptive layers + splash)
